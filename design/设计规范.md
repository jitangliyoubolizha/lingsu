> 版本：v0.2　|　状态：产品方确认稿（待开发）

## 1. 设计定位

- **风格**：新中式（Modern Chinese Classic）。不追求极简，需具备古籍的厚重感与沉浸感。
- **气质关键词**：宣纸、水墨、朱砂、靛青、界行、折扇、印章。
- **红线**：全产品不出现任何现代医疗诊断、治疗、用药推荐暗示；合规文案按第 6 节原文一字不差。
- **平台**：手机优先（基准 390 × 844），响应式，适配桌面；PWA 可安装。

### 2.2 字体

| 令牌 | 字体 | 用途 |
|---|---|---|
| `font-serif` | Noto Serif SC（宋体类） | 古籍原文、页面大标题、方剂名、章节名 |
| `font-sans` | Noto Sans SC | 按钮、标签、统计、导航、表单等现代 UI 元素 |

- 加载：开发阶段可临时使用 Google Fonts `<link>`（Noto Serif SC 200–900、Noto Sans SC 100–900）；均为 **SIL OFL 免费商用字体**，PWA 离线验收前必须自托管 woff2，方案见 `design/视觉资源准备方案.md`。
- 可选：霞鹜文楷 LXGW WenKai（OFL 免费商用）可用于古文引文、注解等装饰性文字，非必须。
- 字号阶梯：原文 24–28px（行高 1.6–1.8）；大标题 28–32px；卡片标题 16–18px；正文 14px；辅助 12–13px；**正文不小于 12px**。
- 设置页提供字号三档（小/中/大）：小 = 原文 22px，中 = 26px，大 = 30px（其余按比例缩放）。

### 2.4 间距与尺寸

- 页面左右安全边距 20px；卡片内边距 14–20px；卡片间纵向间距 12–16px。
- 触控目标：主按钮高 48–52px；选项卡高 56px；图标钮 36×36px。
- 底部吸底元素下方保留 ≥14px 安全区，并适配 `env(safe-area-inset-bottom)`。

## 3. 图标规范

1. **通用交互**：一律使用线性图标（lucide），水墨黑 `#2B2720`，描边粗细 1.5–2：
   - 搜索=放大镜 `search`；收藏=`star`（激活态赭黄）；首页=`house`；刷题=`file-text`；我的=`user`；返回=`chevron-left`；展开=`chevron-up/down`；关闭=`x`；正确=`check`；错误=`x`；警告=`triangle-alert`；朗读=`volume-2`；设置=`settings`；备份=`download/upload`；日历=`calendar`。
   - ⚠️ lucide 新版命名：`house`（不是 home）、`triangle-alert`（不是 alert-triangle）。
2. **业务特色图标**（定制 SVG，见交付物）：印章「灵」（朱砂方章白文，App 标识）、葫芦（连续打卡统计）、折扇纹（分隔装饰线）、找方入口=九宫格 `layout-grid`（百子柜意象）。
3. 图标一律与文字同色或 `ink-muted`；激活/选中态才用朱砂。

## 6. 合规视觉红线（开发必须遵守）

1. **全局底部常驻提示**：主布局所有页面底部一条低调纸色窄条（首次协议页除外；条文详情/搜索页由自带横幅替代，避免叠加），文案 `仅供学习研究，不构成医疗建议，请勿自行用药` + 「内容纠错」入口（`/feedback`）；不可关闭、不可折叠。
2. **首次进入协议要点**（同意前只出现一次）：本工具仅供学习研究；不构成医疗建议；处方须由执业医师开具；原书剂量为古代度量衡，不可自行照方抓药；身体不适应及时就医；条文可能存在错误，可点击底部『内容纠错』反馈。
3. **条文详情页吸底警告横幅**（不可关闭、不可折叠，白字+警告图标，一字不差）：「仅供学习研究，不构成医疗建议，请勿自行用药」+ 「内容纠错」入口；全局窄条在该页让位。
4. **搜索页/症状检索底部**固定一行：`仅供学习研究，不构成医疗建议`（muted 小字或吸底窄条）+ 「内容纠错」入口；全局窄条在该页让位。
5. **方剂详情页剂量换算警告**（面板内紧贴换算内容，红字粗体+警告图标，一字不差）：「学术探讨，非用药指导」；页尾安全提示保留。
6. 全站任何位置不得出现「诊断」「治疗方案」「推荐用药」等表述；不设功效/主治字段。

## 7. 给开发的实现约定

- 样式：Tailwind CSS v4（`@import "tailwindcss"`），设计令牌落在 `:root` 的 CSS 变量（见 2.1 映射），组件类名引用变量，禁止硬编码色值。
- 字体：开发阶段可临时用 `<link>` 加载 Google Fonts；PWA 离线验收前必须改为自托管 woff2（见 `design/视觉资源准备方案.md`）。衬线/无衬线各定义一个工具类（如 `.font-serif`），禁止内联 font-family。
- 布局换算：`fill_container` → `flex-1`；`fit_content` → `w-fit/h-fit`；吸底元素用 `fixed` + 底部安全区 padding。
- 图标：lucide 组件直接引用（注意 `house`/`triangle-alert` 新命名）；三个定制 SVG（印章、葫芦、折扇纹）从 `design/preview/` 的 HTML 中提取 path 原样复用，不得重绘。
- 背诵卡三态按钮与错题反馈色（绿/金/红）语义全局唯一，不得挪用。
