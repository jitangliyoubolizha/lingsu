## 2. 定制 SVG 提取

### 2.1 源位置

| 图标 | 源文件 | 容器标识 |
|---|---|---|
| 印章「灵」 | `design/preview/s1-dash.html` 或 `lingsu-prototype-tailwind.html` | `data-pencil-name="印章 · 灵"` |
| 葫芦 | `design/preview/s1-dash.html` 或 `lingsu-prototype-tailwind.html` | `data-pencil-name="葫芦"` |
| 折扇纹 | `design/preview/s4-lit.html` 或 `lingsu-prototype-tailwind.html` | `data-pencil-name="折扇纹分隔线"` |

### 2.2 建议目录

```
src/assets/svg/
  seal.svg
  gourd.svg
  fan-divider.svg
```

### 2.3 提取要求

- 印章「灵」由多个 `<svg>` 叠加组成，建议从 Pencil 源文件导出，或由开发将多个 path 合并为一个 SVG；
- 葫芦、折扇纹可直接提取为独立 SVG；
- 提取后不得重绘，保持原 path 不变；
- 提取完成后在 `design/README.md` 登记文件位置。

## 3. PWA 图标方案

### 3.1 图标尺寸

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `icon-192.png` | 192×192 | PWA 常规图标 |
| `icon-512.png` | 512×512 | PWA 大图标 |
| `maskable-512.png` | 512×512 | 自适应图标，四周留安全边距 |
| `favicon.ico` | 多尺寸 | 浏览器标签页 |
| `apple-touch-icon.png` | 180×180 | iOS 主屏图标 |

### 3.2 建议目录

```
public/icons/
  icon-192.png
  icon-512.png
  maskable-512.png
  favicon.ico
  apple-touch-icon.png
```

### 3.3 生成方式

- 以印章「灵」SVG 为源图；
- 使用 sharp / ImageMagick / 在线工具导出 PNG；
- maskable 图标需在四周保留至少 20% 安全边距；
- 工程初始化后补充到 `vite-plugin-pwa` 的 manifest 配置。

## 4. 字体自托管方案

### 4.1 字体文件

以下字体均为 **免费可商用**（SIL OFL 1.1 或等价开放许可），可放心用于商业项目并自托管。

| 字体 | 风格 | 建议文件 |
|---|---|---|
| Noto Serif SC（思源宋体） | 衬线/宋体，适合古籍原文、大标题、方剂名 | `noto-serif-sc-400.woff2`、`noto-serif-sc-700.woff2` |
| Noto Sans SC（思源黑体） | 无衬线/黑体，适合按钮、标签、统计、导航 | `noto-sans-sc-400.woff2`、`noto-sans-sc-500.woff2`、`noto-sans-sc-700.woff2` |
| 霞鹜文楷 LXGW WenKai（可选） | 楷体，适合古文引文、注解、装饰性文字 | `lxgw-wenkai-regular.woff2`、`lxgw-wenkai-bold.woff2` |

> 霞鹜文楷不是必须项。如果想让“每日一句”“名家注解”更有古籍手写感，可以选用；不用也不影响主体设计。

### 4.2 建议目录

```
public/fonts/
  noto-serif-sc-400.woff2
  noto-serif-sc-700.woff2
  noto-sans-sc-400.woff2
  noto-sans-sc-500.woff2
  noto-sans-sc-700.woff2
  lxgw-wenkai-regular.woff2   # 可选
  lxgw-wenkai-bold.woff2      # 可选
```

### 4.3 CSS 示例

```css
@font-face {
  font-family: 'Noto Serif SC';
  font-style: normal;
  font-weight: 400;
  font-display: swap;
  src: url('/fonts/noto-serif-sc-400.woff2') format('woff2');
}

@font-face {
  font-family: 'Noto Sans SC';
  font-style: normal;
  font-weight: 400;
  font-display: swap;
  src: url('/fonts/noto-sans-sc-400.woff2') format('woff2');
}
```

### 4.4 获取来源

| 字体 | 获取方式 |
|---|---|
| Noto Serif SC / Noto Sans SC | Google Fonts 下载，或 GitHub 的 Source Han Serif / Source Han Sans 项目 |
| 霞鹜文楷 | GitHub `lxgw/LxgwWenKai` Releases 下载 |

### 4.5 注意事项

- 以上字体均为免费商用，无需付费授权；
- 字体文件较大，建议只保留需要的字重；
- 使用 `font-display: swap` 避免文字不可见；
- 上线前用生产构建验证离线环境字体正常加载；
- 若暂时未自托管，开发阶段可继续用 Google Fonts，但 PWA 离线验证前必须替换。

---

## 5. 执行顺序

1. 工程初始化后，先提取定制 SVG；
2. 用 SVG 生成 PWA 图标；
3. 下载并放入字体文件；
4. 更新 manifest 与 CSS；
5. 生产构建验证离线可用。
