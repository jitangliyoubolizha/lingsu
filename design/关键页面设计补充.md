## 2. 条文列表页

### 2.1 布局

```
┌─────────────────────────┐
│ ←  辨太阳病脉证并治上     │
│ [全部][未学][学习中][已掌握][收藏] │
│                          │
│ 001 太阳之为病，脉浮……  ● │
│ 002 太阳病，发热，汗出…  ☆ │
│ 012 太阳中风，阳浮而阴弱…  │
│ ...                      │
└─────────────────────────┘
```

### 2.2 规则

- 顶栏：返回 + 篇名 + 筛选；
- 列表行：条文号 + 原文首句 + 状态标记；
- 状态标记：未学无标记 / 学习中圆点 / 已掌握对勾 / 收藏星标；
- 筛选为胶囊标签，单选；
- 行高 ≥ 44px，点击进入条文详情。

## 5. 搜索页

### 5.1 布局

```
┌─────────────────────────┐
│ ←  [🔍 发热 汗出 恶风] 取消 │
│                          │
│ 条文（3）                 │
│ 001 太阳之为病……发热……  │
│ 012 太阳中风……翕翕发热…  │
│ 方剂（1）                 │
│ 桂枝汤                   │
│ 药物（0）                 │
│                          │
│ 仅供学习研究，不构成医疗建议  │
└─────────────────────────┘
```

### 5.2 规则

- 输入框 autofocus，支持空格分隔多关键词；
- 结果分组：条文 / 方剂 / 药物；
- 命中关键词朱砂高亮；
- 底部固定合规提示：`仅供学习研究，不构成医疗建议`；
- 不给出诊断、不推荐方剂。

## 9. 通用状态

所有页面需覆盖：

- 空状态：无搜索结果、无错题、无收藏；
- 加载状态：骨架屏或转圈；
- 错误状态：内容加载失败时显示重试；
- 安全区：底部吸底元素适配 `env(safe-area-inset-bottom)`。
