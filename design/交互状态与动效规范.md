# 交互状态与动效规范

> 版本：v0.1
> 配套：`design/设计规范.md`
> 用途：补充组件状态、通用状态和动效规则，开发时按此实现。

---

## 1. 组件状态

### 1.1 按钮

| 状态 | 样式 |
|---|---|
| 默认 | 按 `设计规范.md` 主/次按钮 |
| 按下 | 背景加深一档，轻微缩放 `scale(0.98)` |
| 禁用 | 透明度降至 50%，不可点击 |
| 加载 | 显示小号 spinner，文字保留或变为“处理中” |

### 1.2 输入框 / 搜索框

| 状态 | 样式 |
|---|---|
| 默认 | 背景 `paper-card`，描边 `border-paper` |
| 聚焦 | 描边变 `indigo`，可加 2px 浅靛青外圈 |
| 错误 | 描边变 `red`，下方显示错误文字 |
| 禁用 | 背景 `paper-deep`，文字弱化 |

### 1.3 卡片

| 状态 | 样式 |
|---|---|
| 默认 | 卡片阴影 |
| 按下 | 阴影加深，背景轻微变化 |
| 选中 | 描边 `cinnabar` 或 `indigo`，视语义而定 |
| 禁用 | 降透明度 |

### 1.4 标签 / 胶囊

- 默认：`paper-deep` 底；
- 选中：朱砂实底白字；
- 可点击标签需有按下反馈。

## 2. 通用页面状态

### 2.1 空状态

- 内容：一枚线性插图或印章风格小图 + 一句说明 + 可选操作按钮；
- 示例：“未找到相关内容”“暂无错题”“暂无收藏”。

### 2.2 加载状态

- 优先使用骨架屏；
- 无法骨架屏时使用居中 spinner；
- 加载时间超过 2s 时显示“正在加载…”提示。

### 2.3 错误状态

- 内容：警告图标 + 错误说明 + “重试”按钮；
- 错误说明使用 `ink-secondary`，不使用刺眼红底。

## 3. 弹层组件

| 组件 | 规则 |
|---|---|
| Toast | 顶部或底部轻提示，2–3 秒自动消失，不阻塞操作 |
| Dialog | 居中卡片，带标题、内容、主/次按钮；遮罩半透明水墨黑 |
| BottomSheet | 底部滑出，圆角 16，用于选择类操作 |
| ActionSheet | 底部操作列表，点击遮罩关闭 |

- 所有弹层需适配底部安全区；
- 关闭按钮触控目标 ≥ 36px。

## 4. 动效规则

### 4.1 时长与缓动

| 场景 | 时长 | 缓动 |
|---|---|---|
| 背诵卡翻转 | 300ms | ease-in-out |
| 折叠面板展开 | 200ms | ease-out |
| 页面切换 | 250ms | ease-out |
| 弹层滑入 | 250ms | ease-out |
| 按钮按下 | 100ms | ease-out |
| 打卡成功反馈 | 400ms | spring / ease-out |

### 4.2 关键动效

1. **背诵卡翻转**：3D 翻转，正面提示 → 背面原文；
2. **折叠面板**：高度 + 透明度渐变，折扇纹分隔线保持；
3. **页面切换**：轻微淡入 + 水平滑动；
4. **打卡成功**：葫芦或印章图标弹出 + 轻缩放，可加轻微“完成”反馈色；
5. **错题反馈**：选项背景 200ms 变色，解析面板 250ms 滑入；
6. **按钮触控**：按下 `scale(0.98)` + 背景加深。

### 4.3 减少动效

- 支持 `prefers-reduced-motion: reduce`；
- 开启后关闭翻转、滑动、缩放动画，只保留透明度变化或直接切换。

## 5. 色彩反馈语义

| 场景 | 颜色 |
|---|---|
| 正确 / 记得 | `green` / `green-soft` |
| 模糊 / 收藏 | `gold` |
| 错误 / 忘了 / 警告 | `red` / `cinnabar-soft` |
| 选中 / 强调 | `cinnabar` |
| 链接 / 焦点 | `indigo` |

这些颜色语义全局唯一，不得挪用。
