# 交互状态与动效规范

> 版本：v0.1
> 配套：`design/设计规范.md`
> 用途：补充组件状态、通用状态和动效规则，开发时按此实现。

---

## 1. 组件状态

### 1.1 按钮

| 状态 | 样式 |
|---|---|
| 默认 | 按 `设计规范.md` 主/次按钮 |
| 按下 | 背景加深一档，轻微缩放 `scale(0.98)` |
| 禁用 | 透明度降至 50%，不可点击 |
| 加载 | 显示小号 spinner，文字保留或变为“处理中” |

### 1.2 输入框 / 搜索框

| 状态 | 样式 |
|---|---|
| 默认 | 背景 `paper-card`，描边 `border-paper` |
| 聚焦 | 描边变 `indigo`，可加 2px 浅靛青外圈 |
| 错误 | 描边变 `red`，下方显示错误文字 |
| 禁用 | 背景 `paper-deep`，文字弱化 |

### 1.3 卡片

| 状态 | 样式 |
|---|---|
| 默认 | 卡片阴影 |
| 按下 | 阴影加深，背景轻微变化 |
| 选中 | 描边 `cinnabar` 或 `indigo`，视语义而定 |
| 禁用 | 降透明度 |

### 1.4 标签 / 胶囊

- 默认：`paper-deep` 底；
- 选中：朱砂实底白字；
- 可点击标签需有按下反馈。

---

## 2. 通用页面状态

### 2.1 空状态

- 内容：一枚线性插图或印章风格小图 + 一句说明 + 可选操作按钮；
- 示例：“未找到相关内容”“暂无错题”“暂无收藏”。

### 2.2 加载状态

- 优先使用骨架屏；
- 无法骨架屏时使用居中 spinner；
- 加载时间超过 2s 时显示“正在加载…”提示。

### 2.3 错误状态

- 内容：警告图标 + 错误说明 + “重试”按钮；
- 错误说明使用 `ink-secondary`，不使用刺眼红底。

---

## 3. 弹层组件

| 组件 | 规则 |
|---|---|
| Toast | 顶部或底部轻提示，2–3 秒自动消失，不阻塞操作 |
| Dialog | 居中卡片，带标题、内容、主/次按钮；遮罩半透明水墨黑 |
| BottomSheet | 底部滑出，圆角 16，用于选择类操作 |
| ActionSheet | 底部操作列表，点击遮罩关闭 |

- 所有弹层需适配底部安全区；
- 关闭按钮触控目标 ≥ 36px。

## 4. 动效规则

### 4.1 时长与缓动

缓动令牌定义于 `style.css` 的 `@theme`（Tailwind v4 自动生成 `ease-out-soft` / `ease-spring` 工具类），自定义动画用 `var()` 引用；时长档位：按压 120ms、颜色/图标 200ms、进场与转场 220–300ms、打卡印章 450ms。

| 令牌 | 曲线 | 用途 |
|---|---|---|
| `--ease-out-soft` | `cubic-bezier(0.22, 1, 0.36, 1)` | 进场、展开、位移——快出缓停不拖沓 |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 轻微回弹：图标弹入等小元素 |

| 场景 | 时长 | 缓动 |
|---|---|---|
| 背诵卡翻转 | 300ms | ease-out-soft |
| 折叠面板展开 | 200ms | ease-out-soft |
| 页面切换 | 退场 100ms / 入场 220ms | ease-in / ease-out-soft |
| 弹层滑入 | 面板 250ms + 遮罩 200ms | ease-out-soft |
| 按钮按下 | 120ms | ease-out-soft（pressable） |
| 打卡成功反馈 | 450ms | 印章曲线 `cubic-bezier(0.2, 0.9, 0.3, 1.1)` |
| 卡片堆层叠重排 | 450ms | ease-out-soft（大面幅重排不用过冲曲线，防扇形瞬时外溢） |
| 卡片堆拖拽回弹 | motion 弹簧（stiffness 260 / damping 20，带入松手速度） | spring |

### 4.2 关键动效

1. **背诵卡翻转**：3D 翻转，正面提示 → 背面原文；
2. **折叠面板**：高度 + 透明度渐变，折扇纹分隔线保持；
3. **页面切换**：旧页 100ms 纯淡出让位，新页自下轻浮 6px + 淡入（220ms，`ease-out-soft`）；**不得整页旋转或大幅横移**；
4. **打卡成功**：葫芦或印章图标弹出 + 轻缩放，可加轻微“完成”反馈色；
5. **答题反馈**：选项背景 200ms 变色；答对图标 `pop-in` 轻弹（250ms spring），答错选中项 `shake-x` 摇头（300ms）；解析面板 250ms 滑入；
6. **按钮触控**：`pressable` 类——按下 `scale(0.98)`（120ms），贴到按钮、选项行、卡片类可点元素（BaseButton 已内置同款）；
7. **列表编舞（stagger）**：刷题/错题巩固选项用 `TransitionGroup` + `appear`，逐项错峰 40ms（nth-child 2~8 延迟 40–280ms 封顶）；key 携带题目序号，切题时重新入场；leave 用 `display:none` 即时让位；
8. **弹层（BottomSheet / Dialog）**：遮罩淡入 200ms + 面板自下滑入 250ms（`sheet-*` 系列类，`Transition :duration` 驱动），不得瞬时硬切；
9. **首页经典条文卡片堆**（`CardStack.vue`，React Bits「Stack」Vue 移植）：拖拽顶牌送底、松手以 motion 弹簧带速度回弹（3D 倾斜随位移 ±100px → ∓60°）；层叠姿态重排 450ms `ease-out-soft`；点击顶牌轮换；自动轮换 5s（悬停/切后台/拖拽中暂停）；触摸端卡片 `touch-action: pan-y`——横向滑动拖拽换牌、纵向滑动照常滚动页面，送底阈值随卡宽自适应（40% 卡宽，桌面仍用 sensitivity）；`prefers-reduced-motion` 下 JS 侧单独停用自动轮换、回弹即时归位（定时器驱动不受全局 CSS 兜底覆盖）。**扇形几何防溢出**：宽卡扇形的外溢量 ∝ 卡宽 × sin(总倾角)，绕角部原点旋转时负角度卡片角会沉入下方相邻卡片区——故首页取 `rotation-step 1.5°`、随机幅度 ±4°（`random-amplitude`，原版 ±5）、展开原点 `50% 92%`（底部居中，外溢比角部原点约减半），并预留上下呼吸间距（`mt-6 mb-12`）；实测桌面全轮换周期扇形与相邻区块最小净距 10px、移动端 32px，无横向溢出。
10. **条文详情整页横滑翻条**（E-15，`useSwipeNavigate`）：详情页为 **[上一页｜当前页｜下一页] 三页轨道**，当前页与相邻页共用同一内容组件（`ClausePageContent`），相邻页副本 `inert + aria-hidden` 纯预览（顶栏静态化、不加载笔记）；**三槽位恒渲染**（无数据时空占位），保证居中基准在邻居异步加载前后不变，杜绝版面错位；**页间 24px 间距**（`gap-6`，位移基准 `calc(-100% - 24px)`），拖动中页与页有自然间隙；内容柱根元素 `overflow-x-clip`（clip 不创建滚动容器，顶栏吸顶不受影响）——相邻页在任何断点都不越过内容柱（桌面宽屏静止时完全不可见，移动端不侵入两侧边距带），翻页在内容柱窗口内进行。仅触摸/笔启用（鼠标端与文本选择冲突，走键盘 ←/→ 与底部链接）；轨道 `touch-pan-y`，起点落在 `a/button/textarea/input/select/[contenteditable]` 内不启动；水平意图判定（|dx| > 8px 且 |dx| > |dy|）后**整条轨道跟手**，尽头方向 rubber-band 阻尼（×0.3）；松手 **>25% 页宽或水平速度 >0.5px/ms** 翻页，否则 motion 弹簧（210/22）带速度回弹。**拖动反馈**：整页 3D 微倾（`perspective(1100px) rotateY` ≤4°）+ 随进度轻微缩小（≤1.2%），纸页被推动的实感；翻页交接完成 `navigator.vibrate(8)` 微震动（不支持的平台静默）。**交接**：松手后轨道滑动至相邻页就位（260ms `ease-out-soft`），完成后瞬时换页（`page-instant` 转场无第二次过渡；副本与真实页同组件，换页前后像素一致无缝衔接）；动画落定有 **700ms 超时兜底**（无渲染帧环境下 `finished` 永不 resolve 时直接就位换页，手势不卡死）；期间 `pagerSettling` 抑制 scrollBehavior 回顶——**滑动翻页落点保持拖动时的阅读位置**（链接/键盘翻条仍回顶）。翻条方向只在导航起点写入、转场期间不变（残留值由「从非条文页进入详情」守卫清除，禁止转场结束后翻动 Transition 的 mode/name）。条文间翻页跳过区块编舞与印章动画（整页一体就位），仅从列表/外链进入时播放。`prefers-reduced-motion` 由全局兜底覆盖。同一导航入口供滑动 / 键盘 / 底部链接三种方式共用。

11. **主 tab 切换反馈**（E-15，产品方反馈「切换反馈不明显」）：四个主 tab（首页/刷题/统计/我的）之间切换按 **tab 左右顺序方向性滑动**（复用 `page-next`/`page-prev` 并行转场，切向右侧 tab 新页自右滑入）；激活项**图标 spring 弹跳**（`nav-icon-pop`：scale 0.7→1.18→1，320ms `ease-spring`，仅激活瞬间播放一次）+ 顶部**朱砂指示条**渐现（`nav-indicator`：scaleX 0.3→1 + 淡入，250ms `ease-out-soft`）；按住整项轻微缩小（`nav-press` 0.94，120ms）。桌面侧边导航同款按压与弹跳（激活已有底色胶囊）。非 tab 路由进出不启用方向性滑动，走默认页面转场。

### 4.3 减少动效

- 支持 `prefers-reduced-motion: reduce`；
- 采用**全局兜底**规则：开启后所有动画与过渡压至 0.01ms（等效直接切换），新增动效默认被覆盖，无需逐条适配。

## 5. 色彩反馈语义

| 场景 | 颜色 |
|---|---|
| 正确 / 记得 | `green` / `green-soft` |
| 模糊 / 收藏 | `gold` |
| 错误 / 忘了 / 警告 | `red` / `cinnabar-soft` |
| 选中 / 强调 | `cinnabar` |
| 链接 / 焦点 | `indigo` |

这些颜色语义全局唯一，不得挪用。
