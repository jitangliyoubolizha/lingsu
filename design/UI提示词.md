# 关键页面 UI 提示词

> 用途：给 AI 设计工具或前端实现使用的页面 UI 提示词。
> 风格基准：`design/设计规范.md` + `design/关键页面设计补充.md`。
> 通用设定：手机优先，基准 390×844；新中式风格；宣纸暖米白背景；朱砂主色；衬线用于古籍原文/大标题，无衬线用于 UI 元素。

---

## 0. 通用风格前缀

以下段落可粘贴到每个页面提示词前：

```
请设计一款手机端 App 页面，尺寸 390×844，新中式（Modern Chinese Classic）风格。
背景为宣纸暖米白 #FAF9F6，卡片为 #FFFDF8，描边 #E4D9C3。
主色为朱砂红 #8B0000，次色为靛青 #35506B，点缀金色 #C9A227。
正文用水墨黑 #222222，次要文字 #57534A，弱化文字 #8C8677。
大标题和古籍原文使用衬线字体 Noto Serif SC，按钮/标签/导航使用无衬线 Noto Sans SC。
圆角：卡片 16px，按钮/输入框 12px；阴影轻柔，具有纸张质感。
图标使用线性风格 lucide 图标。
底部预留安全区 env(safe-area-inset-bottom)。
整体气质：古籍、克制、沉浸、可长期使用，不花哨。
```

## 1. 搜索页

```
设计《灵素》App 的搜索页，手机优先，390×844，新中式风格。

页面结构：
- 顶栏：左侧返回箭头，中间搜索输入框（自动聚焦），右侧“取消”文字按钮。
- 搜索框：高 44，圆角 12，背景 #FFFDF8，描边 #E4D9C3，内有放大镜图标和占位文字“输入条文、方剂、药物关键词”。
- 下方结果区域按分组展示：
  1. “条文”分组，显示条文号和原文首句，命中关键词用朱砂 #8B0000 高亮；
  2. “方剂”分组，显示方名和类方标签；
  3. “药物”分组，显示药名和别名。
- 每组标题：无衬线 13px，次要文字 #57534A，带分组计数。
- 空状态：无结果时显示“未找到相关内容”和一枚印章风格插图。
- 底部固定一行合规提示：“仅供学习研究，不构成医疗建议”，弱化文字 #8C8677，小字。

视觉要求：结果列表行高舒适，行间距 12–16px；高亮使用朱砂但不要刺眼；整体像古籍索引页，清晰安静。
```

## 2. 统计页

```
设计《灵素》App 的统计页，手机优先，390×844，新中式风格。

页面结构：
- 顶栏：左侧返回箭头，居中标题“统计”。
- 第一块：月历打卡热力图。7 列（周一至周日）圆角小方格，颜色按打卡强度从浅到深：#EFD3C8 → #D99A8C → #C66A5E → #8B0000；今天格子加朱砂描边。
- 第二块：指标卡组，使用卡片容器，展示：
  - 连续打卡 12 天
  - 累计学习 45 天
  - 已学 30 条
  - 学习中 8 条
  - 已掌握 20 条
  - 待复习 6 条
  数字用衬线大号，标签用无衬线小字。
- 第三块：篇章进度列表。每行显示篇名、进度条（6px 高，朱砂填充）、百分比，例如“太阳病上篇 30/30 100%”。
- 第四块：记忆保持率趋势折线图。折线用朱砂 #8B0000，网格线用 #E4D9C3，坐标文字用 #8C8677。

视觉要求：信息密度较高但要有呼吸感；卡片之间留 12–16px；整体像一本学习账册，数字清晰，不堆砌。
```

## 3. 方证对比页

```
设计《灵素》App 的方证对比页，手机优先，390×844，新中式风格。

页面结构：
- 顶栏：左侧返回箭头，标题“方证对比”，右侧“完成”按钮。
- 已选方剂区：横向胶囊标签展示已选方名，例如“桂枝汤”“麻黄汤”，旁边有“+ 添加方剂”按钮。
- 对比表格：横向可滚动表格，第一列为对比维度，后续每列为一首方剂。
  行维度：组成、主症、脉象、病机、相关条文。
  表头：方名，背景可用 #F3EDE1 或朱砂底白字。
  单元格：衬线 13–14px，行高舒适；病机无法推导时显示“待补充”。
- 表格下方可加一句小字说明：“主症/脉象/病机由相关条文自动推导，仅供学习研究。”

视觉要求：像古籍中的方剂对照表，竖排/横排清晰，分隔线用 #E4D9C3；横向滚动时表头可固定，保持可读性。
```

## 4. 协议页（首次进入/用户协议）

```
设计《灵素》App 的首次进入/用户协议页，手机优先，390×844，新中式风格。

页面结构：
- 页面中央偏上：朱砂方章“灵”字印章，印章下方产品名“灵素”，再下方一行小字“伤寒论学习工具”。
- 中部：一段产品定位说明，使用衬线标题 + 无衬线正文，内容强调“仅供学习研究，不构成医疗建议”。
- 协议要点列表（可选）：用小图标 + 文字列出：
  · 仅供学习研究
  · 不构成医疗建议
  · 处方须由执业医师开具
  · 原书剂量为古代度量衡，不可自行照方抓药
  · 身体不适应及时就医
- 底部：主按钮“同意并开始”（朱砂底白字，高 48–52，圆角 12），次按钮“查看用户协议”（描边按钮）。
- 若为协议全文页：顶部返回，正文为长文排版，段落间距舒适，标题用衬线，正文用无衬线 14px，行高 1.8。

视觉要求：庄重、可信、像打开一本古籍前的扉页；不要有压迫感，留白充足。
```

## 5. 列表页（条文列表）

```
设计《灵素》App 的条文列表页，手机优先，390×844，新中式风格。

页面结构：
- 顶栏：左侧返回箭头，中间篇名“辨太阳病脉证并治上”，右侧可放筛选图标。
- 筛选区：一行胶囊标签，可横向滚动，选项：全部、未学、学习中、已掌握、已收藏。
- 列表：每行显示：
  · 条文号，如“001”，衬线，次要色；
  · 原文首句，如“太阳之为病，脉浮……”，衬线 15–16px，最多一行省略；
  · 右侧状态标记：学习中圆点 / 已掌握对勾 / 收藏星标（金色）。
- 行高 ≥ 44px，分隔线细且淡 #E4D9C3。
- 空状态：筛选无结果时显示“暂无条文”和简单插图。

视觉要求：像古籍目录页，条目清晰、可快速扫读；选中/按下状态要有轻微纸面反馈。
```

### 5.1 列表页变体：方剂列表

```
设计《灵素》App 的方剂列表页，手机优先，390×844，新中式风格。

页面结构：
- 顶栏：左侧返回箭头，标题“方剂”，右侧搜索图标。

- 分隔线淡 #E4D9C3，行高舒适。

视觉要求：像方书目录，层级清楚，组与组之间留白明显。
```

## 6. 我的页

```
设计《灵素》App 的“我的”页，手机优先，390×844，新中式风格。

页面结构：
- 顶栏：左侧“我的”，右侧设置图标。
- 用户信息卡：未登录状态，显示一枚印章或头像占位，下方文字“未登录 · 数据仅保存在本机”。
- 功能列表：
  · 收藏
  · 错题本
  · 数据备份
  · 设置
  · 免责声明
  · 内容来源
  · 版本 v0.1.0
- 每行：左侧线性图标（水墨黑 #222222 或弱化 #8C8677），中间标题，右侧 chevron-right；行高 ≥ 48px。
- 列表使用卡片或分组列表，分隔线淡 #E4D9C3。

视觉要求：简洁、工具感强，像一本个人学习手账的目录页；不要出现医疗、诊断相关暗示。
```

## 7. 使用说明

1. 每个提示词可单独使用，也可在开头追加“通用风格前缀”。
2. 生成设计图后，请对照 `design/设计规范.md` 的令牌值修正颜色、字体和圆角。
3. 合规文案必须一字不差：
   - “仅供学习研究，不构成医疗建议”
   - “学术探讨，非用药指导”
   - 全站不出现“诊断”“治疗方案”“推荐用药”。
