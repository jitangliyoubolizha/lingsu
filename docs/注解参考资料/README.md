# 名家注解参考资料

为条文详情页「名家注解」提供内容来源、写作规范与版权边界。本目录由 AI 整理（2026-08-30），正文引用前一律按项目惯例走「待校对」流程。

## 一、现状

- 条文数据（`content/shanghanlun/sb/chapters/*.yaml`）原有 398 条占位注解：`source: 项目自编（待校对）`、`author: 灵素内容组`，每条一家，`notes: AI 初稿待校对`。**2026-08-30 第一、二批共完成 54 条**（见第七节），其余 344 条仍为占位。
- `docs/数据规范.md` 要求：普通条文 ≥1 家，重要条文 2–3 家，`source` 应为注本书名（如「伤寒来苏集」）、`author` 为注家名（如「柯琴」）。本目录即为落实这一要求的资料库。

## 二、版权红线（先读）

| 类别 | 是否可收录 | 方式 |
|---|---|---|
| 古代公版注家（作者卒于 1950 年代前） | ✅ 可 | 可逐字引用原文 |
| 现代注家（刘渡舟、胡希恕、陈亦人、李克绍、郝万山等） | ⚠️ 不可逐字 | **化用观点**：用自编语言转述其学术观点，`source` 标「参考《书名》」；不得整段复制讲稿原文 |
| 今人整理校注本（出版社点校本） | ❌ 不动 | 点校成果有独立权益；引用以未整理的白文/四库本系统为准 |

- 「非商用」不豁免版权；合理使用的法定范围很窄，批量搬运讲稿不在其列。
- 版权保护「表达」不保护「观点」——化用 = 合法且足够的路径。

## 三、写作口径（三条规则）

1. **逐字引文只出公版注家**，且在 `notes` 或该条注释尾部标「引文待核对原书」，核对通行整理本后方可去掉。
2. **现代观点一律化用**，`source` 命名约定：`参考《刘渡舟伤寒论讲稿》` 这类「参考《书名》」格式；`author` 留空或写「灵素内容组」。
3. 每条 1–3 家，重要条文优先组合「一家公版原文 + 一家观点化用」，与现有 `Annotation { source, author, text }` 结构一一对应；改完跑 `npm run validate:content` 与 `npm run build:content`。
