# 工程初始化方案

> 版本：v0.1
> 状态：已执行（工程骨架已初始化并提交基线）
> 用途：正式开发前按本方案初始化项目骨架，避免污染现有 docs / design / content 目录。

---

## 1. 目标

创建一套可运行的 Vite + Vue 3 + TypeScript + Tailwind CSS v4 工程骨架，并配好：

- 路由：Vue Router（hash 模式）
- 本地存储：Dexie
- 质量工具：ESLint + Prettier + Vitest
- 内容校验：`validate:content`
- PWA：vite-plugin-pwa（先配基础，图标后续补）

---

## 2. 初始化方式

> 当前项目根目录已有 docs/design/content 等文件，**不建议直接在根目录跑 `npm create vite`**，避免覆盖现有文件。

推荐方式：

1. 在临时空目录生成 Vite 骨架；
2. 把 `src/`、`index.html`、`vite.config.ts`、`tsconfig*.json`、`package.json` 等复制到项目根目录；
3. 再按下方清单补齐配置和依赖。

## 4. package.json 脚本

```json
{
  "scripts": {
    "dev": "vite",
    "build": "vue-tsc -b && vite build",
    "preview": "vite preview",
    "lint": "eslint .",
    "format": "prettier --write .",
    "typecheck": "vue-tsc --noEmit",
    "test": "vitest run",
    "validate:content": "tsx scripts/validate-content.ts"
  }
}
```

## 6. Tailwind v4 配置

- `src/style.css` 顶部：

```css
@import "tailwindcss";
```

- `vite.config.ts` 使用 `@tailwindcss/vite` 插件；
- 设计令牌放在 `:root` CSS 变量，映射方式见 `design/设计规范.md` §2.1。

---

## 7. PWA 配置

- 使用 `vite-plugin-pwa`；
- 先配置 manifest：应用名“灵素”、主题色、图标路径；
- 图标和启动图后续放入 `public/`；
- 开发模式不验证离线缓存，生产构建时验证。

---

## 8. CI 工作流

`.github/workflows/ci.yml` 建议：

```yaml
name: CI
on:
  push:
  pull_request:

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: lts/*
      - run: npm ci
      - run: npm run lint
      - run: npm run typecheck
      - run: npm run validate:content
      - run: npm run test
      - run: npm run build
```

---

## 9. 初始化验收标准

- [ ] `npm run dev` 可启动并访问首页；
- [ ] `npm run lint` 通过；
- [ ] `npm run typecheck` 通过；
- [ ] `npm run validate:content` 通过；
- [ ] `npm run test` 通过；
- [ ] `npm run build` 可产出生产包；
- [ ] 生产构建 PWA 可安装、离线可打开（图标补齐后验证）。

---

## 10. 注意事项

1. 不要覆盖现有 `docs/`、`design/`、`content/` 目录；
2. 技术栈版本以 `docs/开发规范.md` 为准，初始化后不得随意更换；
3. 初始化完成后，先提交一次“工程基线”再开始业务开发。
