# GitHub 推送指南

> 适用：WorkBuddy 沙箱 + 本机 Windows，推送 GitHub 仓库（《灵素》等）。
> 一句话结论：**不要用 Bash 里的 `git`（PortableGit），改用系统 Git for Windows + `wincred` 凭据助手。**

## 一、为什么不能直接 `git push`

当前 WorkBuddy 环境里，Bash 默认的 `git` 是 WorkBuddy 自带的便携版 PortableGit：

```
C:\Users\Administrator\.workbuddy\binaries\PortableGit\versions\1.2.0\
```

它**缺少 Windows 凭据助手**（`git-credential-wincred.exe` / `git-credential-manager.exe`），读不到系统凭据管理器里的 GitHub 账号，push 时会报 `401 Unauthorized` 或反复要求输入用户名。

本机另装了正式的 Git for Windows（带完整凭据助手）：

```
C:\Program Files\Git\bin\git.exe   # 版本 2.55.0.windows.4
```

GitHub 凭据存放在 Windows 凭据管理器：`LegacyGeneric:target=git:https://github.com`（用户 `jitangliyoubolizha`）。

## 二、推送命令

统一用系统 Git + `wincred` 凭据助手：

### 情况 A：走代理（Clash 已运行）

`~/.gitconfig` 已给 github.com 配了代理 `http://127.0.0.1:7897`，直接：

```bash
"C:/Program Files/Git/bin/git.exe" -c credential.helper=wincred push origin main
```

### 情况 B：绕过代理直连（Clash 未运行、直连可用时）

```bash
"C:/Program Files/Git/bin/git.exe" -c http.https://github.com.proxy= -c credential.helper=wincred push origin main
```

推 tag：在命令末尾加 `--tags`，例如 `push origin main --tags`。

## 三、先探测网络，再决定走哪条路

```bash
# 测代理是否通
curl -sS -x http://127.0.0.1:7897 -m 8 -o /dev/null -w "%{http_code}" https://github.com

# 测直连是否通
curl -sS --noproxy '*' -m 8 -o /dev/null -w "%{http_code}" https://github.com
```

- 代理返回 `200` → 用「情况 A」（走代理）
- 直连返回 `200`、代理超时 → 用「情况 B」（绕过代理）
- 两个都不通 → 检查 Clash 是否启动、网络是否正常

> 注：这两条路的可用性会随时间变化（曾出现 8-25 直连通/代理不通、8-26 反过来），所以**每次 push 前先探测**，不要凭记忆。

## 四、完整操作流程

1. 改完代码，跑验证：`npm test`、`npm run lint`、`npm run typecheck`、`npm run validate:content`、`npm run build`
2. `git add ...` + `git commit -m "..."`
3. 探测网络（见第三节）
4. 按对应情况执行 push
5. 发布 tag：`git tag vX.Y.Z`，push 时加 `--tags`

## 五、常见问题排查

| 报错 | 原因 | 处理 |
|---|---|---|
| `401 Unauthorized` | 用了 PortableGit 或 helper 没生效 | 确认用系统 Git + `-c credential.helper=wincred` |
| `Failed to connect ... over proxy 127.0.0.1` | 代理未运行 | 启动 Clash，或改用「情况 B」绕过 |
| `Connection was reset` / 连接超时 | 网络波动 | 先探测连通性，再重试 |
| `Could not read Username` | 无凭据或凭据失效 | 检查凭据管理器 `git:https://github.com`，或 GitHub Desktop 重新登录 |

## 六、其他常用 git 操作（同样用系统 Git）

```bash
SYSGIT="C:/Program Files/Git/bin/git.exe"

# 查看远程状态
"$SYSGIT" -c credential.helper=wincred ls-remote origin

# 拉取
"$SYSGIT" -c credential.helper=wincred pull origin main

# 查看远程分支与 tag
"$SYSGIT" -c credential.helper=wincred fetch origin
```
