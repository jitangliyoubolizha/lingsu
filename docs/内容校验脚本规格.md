# 内容校验脚本规格

> 版本：v0.1
> 配套：`docs/数据规范.md` 第 6 节、`docs/工程初始化方案.md`
> 用途：定义 `scripts/validate-content.ts` 的输入、输出、错误格式与校验规则，方便直接实现。

---

## 1. 目标

- 读取 `content/` 下全部 YAML；
- 按 `docs/数据规范.md` 的规则校验；
- 校验失败时给出具体文件、字段和修正建议；
- 供 CI 和本地 `npm run validate:content` 使用。

---

## 2. 输入与输出

### 2.1 输入

- `content/` 目录；
- 以 `book.yaml` 为入口，按 `edition.yaml` 找到版本与篇目文件；
- 读取 `formulas.yaml`、`herbs.yaml`、`symptom-terms.yaml`、`questions.yaml` 及章节文件。

### 2.2 输出

- 成功：打印 `内容校验通过`，退出码 `0`；
- 失败：打印所有错误，退出码 `1`。

---

## 3. 退出码

| 退出码 | 含义 |
|---|---|
| 0 | 校验通过 |
| 1 | 存在内容错误 |
| 2 | 脚本自身运行失败（如文件缺失、YAML 解析失败） |

---

## 4. 错误消息格式

每条错误使用统一格式：

```
[文件路径]:[行号] [错误码] [字段] [问题描述] [修正建议]
```

示例：

```
content/shanghanlun/sb/chapters/taiyang-shang.yaml:5 E1001 clauses[0].translation 缺少白话译文 请补充 translation 字段
content/shanghanlun/sb/formulas.yaml:12 E2003 formulas[0].composition[0].herb 引用不存在的药物 SHL.SB.H.999 请改为存在的药物 ID
```

### 错误码规划

| 错误码 | 含义 |
|---|---|
| E1001 | 必填字段缺失 |
| E1002 | 字段类型错误 |
| E1003 | 枚举值不合法 |
| E2001 | ID 重复 |
| E2002 | ID 格式错误 |
| E2003 | 引用不存在 |
| E2004 | 题目答案越界 |
| E3001 | 禁用词命中 |
| E4001 | 拆分文件合并冲突 |

---

## 5. 校验规则

实现时至少覆盖：

1. ID 唯一且格式正确；
2. 必填字段非空；
3. 条文有原文、译文、至少 1 条注解；
4. 条文/方剂/药物/术语/题目引用完整性；
5. 题目 `answer_index` 在 `options` 范围内；
6. 方剂有 `safety_notice`；
7. 全量内容无禁用词；
8. 同一篇拆分文件合并后无 `no` / `id` 重复。

详细规则以 `docs/数据规范.md` 第 6 节为准。

---

## 6. 实现建议

- 使用 `yaml` 包解析；
- 先建“实体索引”（所有 ID → 位置），再做引用检查；
- 错误收集完一次性输出，不要遇错即停；
- 校验逻辑拆成纯函数，便于单元测试；
- 脚本放在 `scripts/validate-content.ts`，用 `tsx` 运行。

---

## 7. 与构建的关系

- `npm run validate:content` 通过后，才能运行 `scripts/build-content.ts`；
- CI 中 `validate:content` 在 `build` 之前执行。
