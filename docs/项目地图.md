# 项目地图

> 版本：v0.2
> 用途：以后想改某个东西时，快速定位应该去哪个模块/文件找。
> 说明：路径以当前实现为准；开发后如有调整，同步更新本文件。

---

## 1. 快速定位总表

| 我想改什么 | 去哪里找 | 备注 |
|---|---|---|
| 产品需求/功能范围 | `docs/PRD.md` | 改需求先改这里，再动代码 |
| 项目计划/子计划 | `docs/项目计划.md` | 改动子计划、依赖、产物 |
| 开发规范/依赖/提交规则 | `docs/开发规范.md` | 技术栈变更必须先改这里 |
| 学习计划/统计口径 | `docs/学习计划与统计口径.md` | 涉及每日任务、FSRS、统计指标 |
| 内容数据字段/ID/校验规则 | `docs/数据规范.md` | 同时看 `src/data/types.ts` |
| 内容校验脚本行为 | `docs/内容校验脚本规格.md` + `scripts/validate-content.ts` | 错误格式、退出码 |
| 用户协议/免责声明 | `docs/用户协议与免责声明.md` | 改文案后同步首次进入页与全局提示条 |
| 意见反馈/内容纠错 | `src/ui/views/FeedbackView.vue` + `src/ui/feedback.ts` | mailto 发送；改渠道/文案看这里 |
| 测试计划 | `docs/测试计划.md` | 改测试范围、用例清单 |
| 维护节奏/技术债/发布检查单 | `docs/维护与迭代计划.md` | 迭代路线、维护会话流程、季度复盘 |
