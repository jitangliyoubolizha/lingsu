# 灵素 · 伤寒学习 v2

「灵素」——中医经典学习工具项目，当前以《伤寒论》为起点。产品名暂定“灵素”，项目目录名保持“伤寒学习v2”。当前阶段：需求与**视觉设计均已确认**（PRD + 设计规范 + 13 屏原型）；**子计划 0–6 已完成**（工程骨架 + 内容数据层 + 核心 domain 模块 + 本地存储与备份 + UI 框架与 13 个页面 + 核心功能集成 + PWA 与离线）；**子计划 7 内容批量录入与校对进行中**（太阳病上篇 30 条、中篇 31–60 条、下篇 128–147 条已录入）。

**开发前必读：`docs/开发规范.md`（目录结构、技术栈版本、代码风格、热更新规则、Git 提交约定）。所有开发动作必须遵守该规范。**

## 目录使用规则

1. 项目文档一律放 `docs/`，不要放桌面或根目录散落。
2. 你的视觉设计稿放 `design/`。
3. 以后新增书籍内容时，在 `content/` 下按“一本书一个目录”添加，例如 `content/jinkui/`。
4. 程序源代码只放 `src/`，内容数据和程序代码严格分开。
5. 修改需求时，先更新 `docs/PRD.md` 或新增变更记录，再动代码。
